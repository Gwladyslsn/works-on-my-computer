# Pre-Deployment Checklist

> **Student template:** build a checklist for this release before deployment. The headings guide your thinking; the checks themselves are yours to write.

## Release identity

- V1.0.0
- Verify that the version number and release information are correct.

## Target environment

- Production - GitHub Pages
- Verify that the correct repository and branch are selected for deployment.

## Access and prerequisites


- GitHub access
- Verify that the required permissions to deploy to GitHub Pages are available.
- Verify that Git is installed and the repository is up to date.

## Files and configuration

- Verify that all required project files are present.
- Verify that all links, resource paths, and configuration files are correct.
- Verify that no unnecessary or local files will be published.

## Security

- Verify that no passwords, API keys, tokens, or other secrets are included in the project.
- Verify that the GitHub repository permissions and settings are correctly configured.

## Deployment readiness

- Verify that the project works correctly before deployment.
- Verify that all changes have been committed and pushed to the repository.
- Verify that GitHub Pages is configured with the correct deployment source.

## Recovery readiness

- Verify that the previous stable version is available in case of a problem.
- Make sure it is possible to roll back to the previous version if necessary.

## Post-deployment verification prepared

- Verify that the website is accessible through its GitHub Pages URL.
- Check the main pages, links, images, and other resources.
- Check that the website displays correctly on both desktop and mobile.

## Final decision

- Ready to deploy? **Yes**
- If no, what must be resolved first? - all checks must be completed before deployment.
